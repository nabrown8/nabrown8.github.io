COMP 116: Introduction to Scientific Programming

University of North Carolina at Chapel Hill - Spring 2027

Course Description

The goal of this course is to teach non-computer science students the basics of computer programming, and to survey a variety of scientific applications that programming can be applied to. Topics covered will include Python programming, medical imaging, data visualization, epidemiology, and other relevant applications. Problem analysis and algorithm design with examples drawn from simple numerical and discrete problems.

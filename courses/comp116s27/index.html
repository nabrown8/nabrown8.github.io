Course Description

The goal of this course is to teach non-computer science students the basics of computer programming, and to survey a variety of scientific applications that programming can be applied to. Topics covered will include Python programming, medical imaging, data visualization, epidemiology, and other relevant applications. Problem analysis and algorithm design with examples drawn from simple numerical and discrete problems.

Necessary Software

You will need to install Python3 and Jupyter Notebook for this course. We'll discuss this more, but at a high level, Jupyter Notebooks allows you to write lines of code, and Python allows you to run the lines of code you write. Kris Jordan and Alyssa Byrnes did a fantastic job writing up a clear guide on installing Python here. You should follow either section 0 under Windows 10 and 11 Instructions, or sections 0 through 2 under macOS Instructions. Once you have Python downloaded, you'll also need to install Jupyter. At this point, you should be able to open Jupyter Notebook. You're all set!
